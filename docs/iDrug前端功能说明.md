#iDrug平台前端功能说明
##一、前端基础架构与技术支撑
  iDrug系统采用表现层、业务层、模型层、数据层四层架构，其中表现层负责页面交互与结果展示。平台前端采用HTML、CSS与JavaScript实现，整体使用模块化页面结构与统一样式设计，界面主色调采用浅蓝科技风格，以提升系统专业性与可读性，前端通过导航栏实现各功能页面切换，并采用卡片式布局展示核心模块内容，提高页面层次性与交互体验。系统结合登录认证、权限控制等机制保障系统稳定运行，轻量化Web页面支持云服务器远程部署访问，无需本地客户端。
  平台构建结构查询与三维可视化模块，整合PubChem、PDB、DrugBank等公开数据资源，并结合本地结构化知识库，实现药物分子信息、蛋白结构信息及复合物数据的统一查询。在可视化方面，平台基于3Dmol.js实现药物分子、蛋白结构及复合物三维展示，支持旋转、缩放及关键位点高亮等交互操作，提升结果可解释性与用户体验。
##二、各页面界面功能
###2.1首页界面
  首页采用卡片式布局展示平台简介、核心功能入口及技术内容，并通过顶部导航栏实现各模块快速跳转，导航栏包含Home、Recommend、Models、Explore、Data、Profile、Tutorial七大入口，便于用户完成系统浏览与功能访问。页面展示平台定位介绍、四大核心功能卡片、平台分层架构说明、使用教程入口与平台联系方式。

###2.2个性化药物推荐辅助模块界面
  推荐模块采用表单式交互设计，支持药物、靶标及用户画像输入，并展示重排序结果与解释信息。页面分为两大区域：分子输入区域，可填写药物SMILES、蛋白序列，支持多行批量输入；患者画像区域，包含年龄、性别、疾病史、过敏史、医保偏好五项必填信息，疾病史、过敏史可选择填写为None，底部设置Run Recommendation提交按钮，提交后跳转至个性化排序推荐结果页面。

###2.3多场景预测界面
  预测模块支持任务选择、参数输入及结果展示，可自动调用对应模型完成预测。页面顶部为任务选择区，包含药物重定位、新靶标筛选、新药评估、亲和力预测四类独立任务；下方为输入区域，分为药物输入框、蛋白序列输入框，支持单行单样本或分行批量输入，页面底部提供 Run Prediction 运行按钮与 Reset 重置按钮。

###2.4结构查询与 3D 展示界面
  页面分为药物结构查询、蛋白质结构查询、复合物结构查询三大子模块。复合物查询支持输入PDB ID检索，系统优先检索本地缓存，无缓存则调用在线PDB数据库；页面展示复合物基础信息（蛋白名称、配体、关键词等），并提供3D交互视图窗口，支持结构文件导出。药物查询支持CID、SMILES检索，展示分子式、分子量、二维分子结构图；蛋白查询支持PDB、UniProt序列检索，展示蛋白序列、分子重量、绑定组件等元数据。

###2.5数据展示界面
  Data 模块对本地结构化数据分类展示，分为药物结构数据、蛋白结构数据、复合物数据、个性化推荐元数据、疾病 / 过敏标签库，页面支持分页浏览，展示各数据集核心字段说明，同时罗列 PubChem、RCSB PDB、DrugBank 等外部参考数据源。

###2.6注册、登录与用户中心界面
  注册页面提供用户名、密码、选填手机号输入框；登录页面仅保留账号、密码输入项。用户中心（Profile）页面可查看所有保存的预测、推荐历史记录，支持单条记录删除、批量清空结果，同时展示个人账号基础信息。Tutorial教程页面提供分步图文操作指引，覆盖平台全部核心工作流。

##三、前端功能实测效果
###3.1多场景预测功能
  用户登录系统后，在预测模块中输入药物与蛋白信息，并选择对应任务类型，提交预测请求。系统完成模型推理后，跳转预测结果页面。页面顶部展示任务名称、运行状态、执行提示；主体以列表表格展示排名、药物输入、蛋白序列、原始预测分数、预测标签，用户可直观查看不同药物与目标蛋白的相互作用强度，系统能够稳定完成多任务预测，响应流程完整，结果输出清晰。

###3.2结构查询与可视化功能
  分别输入药物CID、蛋白PDB、复合物PDB ID进行测试，药物查询返回分子基础信息与二维结构图；蛋白查询输出蛋白序列、属性标签；复合物页面加载可交互3D结构，支持旋转、缩放、关键区域高亮，能够直观呈现药物与靶点结合关系，提升结果可解释性。


###3.3数据展示模块功能
  在Data模块中切换不同数据类别，包括药物结构数据、蛋白结构数据、复合物数据及个性化推荐元数据，页面支持分页浏览，系统能够稳定加载并展示多类本地结构化数据，分类展示逻辑清晰，为预测、推荐与查询功能提供可靠的数据支撑。

###3.4用户与结果管理功能
系统能够正确完成用户注册、登录及信息校验，并对异常输入进行提示。完成预测、推荐任务后可执行结果保存操作，在用户中心查看全部历史记录，支持单条或批量删除记录，具备完整的用户管理与结果留存前端交互能力。

##四、前端设计优势与创新
  现有DTI相关平台普遍受困于展示形式单一、可视化交互不足、多功能无法一体化集成的短板。本平台前端整合预测、排序、查询、三维可视化、用户管理功能于同一Web系统，创新实现一体化交互页面；构建完整3D分子交互可视化前端组件，解决传统平台仅输出数值列表、结果难以直观解读的痛点；统一导航模块化拆分各业务场景，区分通用DTI预测与个性化药物推荐两套独立工作流，适配科研、教学不同使用人群；轻量化网页端无需本地配置模型环境，依托云服务器即可远程完成全套药物靶点分析操作。开发阶段智能体辅助完成前端页面布局优化、导航栏结构调整及Tutorial教程页面整理，优化页面交互逻辑，提升前端使用流畅度。
