# 一、项目概述

随着新药研发成本持续攀升及药物重定位需求不断增长，传统实验驱动的药物发现模式面临周期长、成本高、成功率低等突出问题，严重制约了生物医药研发的高效推进。药物－靶点相互作用（Drug–Target Interactions，DTI）预测作为计算药物发现的重要方向，能够通过计算机模拟技术快速筛选潜在候选药物，有效提升筛选效率、降低实验成本，已成为人工智能赋能生物医药领域的重要研究热点。但现有 DTI 相关平台，如 DeepPurpose、TargetNet、OncoKB 等，普遍受困于多场景适配不足、结果利用率低、多源数据分散、展示形式单一等短板，难以融合预测、排序、可视化及个性化服务于一体，限制了实际应用价值。

针对上述行业痛点与技术瓶颈，本项目设计并实现了 iDrug——多场景 DTI 预测与个性化药物推荐辅助平台。平台围绕“预测—查询—排序—展示”核心流程，构建完善的多场景 DTI 预测体系，可全面支持药物重定位、新靶标筛选、新药评估及亲和力预测等核心任务；创新引入个性化推荐重排序机制，结合用户研究特征与药物属性信息，对候选结果进行精准优化；整合 PubChem、PDB、DrugBank 等多源权威数据，实现药物与靶点结构查询、数据浏览及分子三维可视化展示。该平台面向药物研发研究人员、生物信息方向师生及数据分析用户，可广泛应用于药物重定位分析、DTI 研究辅助及教学实验场景，具有良好的应用价值与广阔的推广前景。
