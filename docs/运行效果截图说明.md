# 平台运行效果截图说明
## 1. 截图清单与内容说明
项目运行截图统一存放在项目根目录下的 screenshots 文件夹，一共四张，分别介绍如下：
1. 首页截图.png：展示iDrug系统首页页面。页面包含顶部导航栏、项目简介、四大功能模块入口、项目架构说明，实现跳转至预测、药物推荐、结构查询、数据集页面的功能。
2. 预测页面截图.png：为Models多场景DTI‑预测输入界面。页面提供四类预测任务选择框、药物SMILES输入框、蛋白质序列输入框，附带运行预测、重置两个操作按钮，用来提交预测任务。
3. 结果展示截图.png：DTI模型预测完成后的结果页面。以表格形式展示预测排名、药物信息、蛋白序列、预测分数、相互作用标签，登录用户可以保存本条记录。
4. 个性化推荐截图.png：Recommend个性化药物推荐页面。除基础分子输入框外，额外增加患者个人信息表单，录入年龄、病史、过敏信息后，实现药物的个性化重排序。

## 2. 整体运行说明
项目部署在云端服务器，通过浏览器访问Web网页，完整实现首页浏览、DTI预测、个性化药物推荐、结果展示整套业务流程。所有页面交互正常，表单输入、模型调用、结果返回、3D可视化均可正常运行。
